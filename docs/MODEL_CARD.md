# 模型卡

DriveGaussianWorld 是工程验证用的确定性动作条件世界模型，不是自动驾驶基础模型或可部署策略。DGGT 前端使用已有 Waymo 预训练权重并冻结，新增时序网络在真实 KITTI 行车小样本上用 CPU 做短训练。

输入为 3 帧历史 RGB/Gaussian/speed 和独立未来运动条件；默认预测 4 步，约 1.6 秒。输入 RGB 为 96×32；当前 DGGT CPU 验证使用 140×42 左右的输入图像而非原生 518 像素宽度，存在显著分辨率与域外变化。不要把这个设置的输出当作官方 DGGT 复现指标。

世界模型组合 CNN、DeepSets 和 GRU，拥有解析自车运动先验和学习残差。它是真正有优化器、损失、反传、checkpoint 与持出评估的模型；其能力仍受极小数据量限制。默认种子 42、AdamW、梯度裁剪、每 25 步验证、只按 val loss 选权重。

评估报告提供 RGB L1/PSNR、多步自车 ADE/FDE、Gaussian 集合距离和有效采样 mask IoU，以及 RGB-only/无动作/表征来源消融。报告提供日志未来运动条件和无未来运动条件两种设置，后者只用匀速直行场景。日志条件结果不应被当作未知未来动作的预测能力。

已知限制包括：确定性单模态预测、低分辨率输出、相机/车体参考点近似、Gaussian 伪监督、同日小样本域、相邻窗口相关、缺少车道/占据/actor 身份真值、动作来自运动差分而非干预控制。反事实动作在数据中没有成对干预验证，因此动作排序只能展示接口，不能证明因果可控性。

没有自动选择 CUDA 的代码，训练入口只允许 CPU 和有限步数/线程/批大小。现有权重和数据不随源码压缩包分发。运行记录和实际结果见 `RESULTS.md`；基线优于学习模型时如实保留，不挑选 test 结果最好的 epoch。
